# Changelog (история изменений)

## Version 2026.1

*7 ноября 2026 г.*

Первый выпуск настоящего набора определений. За основу взяты определения из российского пакета локализации для Civil 3D, отредактированы в соответствии с иными материалами: сборника MAPINFOW, подборки с портала geobridge, данных с форума геодезист.ру.

Включает 903 определения:

- 174 для ГСК-2011 (игнорируется при записи для PROJ);
- 545 региональных, городских СК для России;
- 33 определений для Украины включая 6 зон СК-63 в "их" редакции (игнорируется при записи для PROJ);
- 151 определение для СК-63;
