# Collection of Russian and post-Soviet coordinate systems

Сборник параметров региональных, городских систем координат для России и стран пост-советского пространства. 

**Дисклеймер №1** : приведенные в настоящем репозитории определения систем координат не являются официальными данными, не копировались с каких-либо материалов под грифами "секретно", "для служебного пользования" и т.д. Определения скопированы из подборок библиотек СК от MapInfo, geobridge, форума geodesist.ru и некоторых иных ресурсов. Часть определений рассчитана эмпирически по общим точкам в двух системах координат. Все совпадения с секретными материалами случайны и не пред-намеренны. Используйте приведенные материалы на свой страх и риск в профессиональной деятельности (нет гарантий на точный пересчет).

**Дисклеймер №2**: автор не ставит под сомнение текущую государственную принадлежность тех или иных территорий третьих стран, сменивших власть и не полностью признанных международным сообществом (приведенные определения не стоит трактовать как экстремизм или иначе); приведенные здесь определения систем координат имеют префикс государства, при котором данная система координат вводилась для определенной территории, а также описание с указанием государственного подчинения. Например, на Крым в составе Украины до 2014 года распространялась зона X СК63 в специальной редакции и в то же время ещё действуют СК63 редакции СССР. Отличия СК в том, что украинская версия имеет ненулевую широту начала, а СССР - сдвиг на север на величину этого "градусного начала"); аналогично про СК для г. Севастополь - для Украины он имел код МСК-85, а в составе России - МСК-92. 

Структура репозитория:
```
-- CalcData: текстовые файлы с данными для расчета параметров некоторых систем координат по общим точкам в программе CPlaneLite
-- OtherData: файлы библиотек СК из других программ или мест;
-- SourceData: непосредственно табличные данные по определениям СК формата TSV (tab separated values), см. корневой readme с деталями
```
P.S. md-файлы редактируются с помощью Obsidian, данные его проекта исключаются посредством .gitignore.
## Использование

Приведенные в репозитории определения с помощью утилит преобразуются в:
- словарь пользовательской библиотеки систем координат для Autodesk AutoCAD Map 3D (Autodesk AutoCAD Civil 3D) в XML-виде;
- файлы CSD пользовательской библиотеки систем координат для продуктов Autodesk на базе файла выше и дополнительных действий, они будут публиковаться в [другом репозитории](https://github.com/GeorgGrebenyuk/MSK_for-Autodesk-Civil-3D);
- SQL-файл для импорта в среду `proj.db` - библиотеки систем координат OSGeo PROJ (используется в QGIS и многих других open source ГИС-продуктах);

## Состав определений

В основном, это системы координат городов и регионов России. Также имеются определения для регионов Беларуси, Украины, Казахстана, TODO - Абхазии, Армении, Азербайджана, Киргизии. 

Для некоторых региональных СК в России имеются 2 варианта - старые от СК63/СК42 и новые на базе СК-95 (имеют в названии такой суффикс) - например, в Ставропольском крае, Владимирской области и пр.

Англоязычные названия для российских субъектов взяты из официального аглоязычного перевода Конституции РФ.
