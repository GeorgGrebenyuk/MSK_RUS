# Collection of Russian and post-Soviet coordinate systems

Сборник параметров региональных, городских систем координат для России и стран пост-советского пространства. 

**Дисклеймер и примечание №1** : приведенные в настоящем репозитории определения систем координат не являются официальными данными, не копировались с каких-либо материалов под грифами "секретно", "для служебного пользования" и т.д. Определения скопированы из подборок библиотек СК от MapInfo, geobridge, форума geodesist.ru и некоторых иных ресурсов. Часть определений рассчитана эмпирически по общим точкам в двух системах координат. Все совпадения с секретными материалами случайны и не пред-намеренны. Используйте приведенные материалы на свой страх и риск в профессиональной деятельности (нет гарантий на точный пересчет).

**Дисклеймер и примечание №2**: приведенные здесь определения систем координат имеют префикс государства, при котором данная система координат вводилась для определенной территории, а также описание с указанием государственного подчинения на момент ввода. Приведенную информацию не следует интерпретировать, как отрицание текущей ситуации (смены государственной принадлежности отдельных территорий третьих стран - здесь, в основном, ряда регионов Украины, вошедших в состав Российской Федерации или Абхазии, ставшей независимой от Грузии). Использование разных префиксов и описаний позволит, как надеется автор, чётко разграничить системы координат, введенные в разное время разными органами того или иного государства, как, например, произошло с Крымом, городами на нём, и некоторыми другими территориями.

Структура репозитория:
```
-- CalcData: текстовые файлы с данными для расчета параметров некоторых систем координат по общим точкам в программе CPlaneLite
-- OtherData: файлы библиотек СК из других источников;
-- SourceData: непосредственно табличные данные по определениям СК формата TSV (tab separated values), см. корневой readme с деталями
```
P.S. md-файлы редактируются с помощью Obsidian, данные его проекта исключаются посредством .gitignore.

Историю обновлений см. в файле [CHANGELOG](./CHANGELOG.md).

Перечень доступных МСК см. в файле [CONTENT](./CONTENT.md).
## Использование

См. раздел [Releases](https://github.com/GeorgGrebenyuk/MSK_RUS/releases). Приведенные файлы формируются с помощью [утилит](https://github.com/GeorgGrebenyuk/MskCsGenerationUtils) в:

| Файл                      | Назначение                                                                                                                                                                                            |
| ------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| AutodeskCSLibrary.xml     | XML-представление пользовательской библиотеки систем координат для Autodesk AutoCAD Map 3D<br>Импортировать командой `MAPCSLIBRARYIMPORT`                                                             |
| AutodeskCSLibrary_CSD.zip | Архив из конфигурационных CSD-файлов, описывающих пользовательскую библиотеку систем координат в Autodesk AutoCAD Map 3D<br>Размещать в `%LOCALAPPDATA%\Autodesk\User Geospatial Coordinate Systems`  |
| OsgeoProjDb.sql           | SQL-запрос на добавление определений в базу данных proj.db (OSGeo PROJ). Используется в QGIS и многих других open source ГИС-продуктах.<br>Добавлять через CLI или вручную используя менеджеры SQLite |
